# CO2 Emission Prediction Using Machine Learning
Welcome to the CO2 Emission Prediction project! This repository contains the code and resources for predicting CO2 emissions from vehicles using various machine learning regression techniques.

## Table of Contents
- Introduction
- Dataset
- Modeling Techniques
- Evaluation
- Contributing
  
## Introduction
  This project aims to predict CO2 emissions from vehicles based on various features such as engine size, fuel consumption, and more. The objective is to compare different regression models and determine the best approach for accurate predictions.

## Dataset
  The dataset used in this project is sourced from kaggle. It contains features like engine size, number of cylinders, fuel consumption (city, highway, and combined), and CO2 emissions.

- Target Variable: CO2 Emissions 
- Features: Engine size, Number of cylinders, Fuel consumption (city, highway, combined), etc.

## Modeling Techniques
- KNeighborsRegressor regression techniques are applied in this project.

## Evaluation
- Model performance is evaluated using r2_score metrics.
